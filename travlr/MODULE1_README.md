# CS-465 Module One — Travlr Getaways

Generated using the Express Generator with the HBS view engine, then populated with the original Travlr static HTML pages under `public/` as instructed on pages 61–75 of the Full Stack Guide.

## Run

1. Open this folder in VS Code.
2. Run `npm install`.
3. Run `npm start`.
4. Visit `http://localhost:3000/index.html` (or `http://localhost:3000`).
5. Capture a browser screenshot showing the site and localhost URL for the submission.

The static HTML pages are in `public/`, their images in `public/images/`, and styles in `public/css/`. The generated `routes/`, `views/`, `bin/`, and `app.js` are preserved for later MVC exercises.

## GitHub

Use your existing cloned `cs465-fullstack` repository. On its `module1` branch, put these generated project contents in the `travlr` project folder (without an extra nested folder). Then run `git add .`, `git commit -m "Baseline Express Website - static only"`, and `git push --set-upstream origin module1`.

Do not submit or commit `node_modules/`.
